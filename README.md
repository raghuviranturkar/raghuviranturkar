## Featured Work

### AI Data Intelligence Platform
[![GitHub](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/raghuviranturkar/ai-data-platform)

Production-grade platform that automates the ML lifecycle from raw data validation to model explainability.

**What it does:**
- Validates datasets and detects quality issues
- Performs automated EDA and feature engineering
- Trains and compares ML models with AutoML
- Explains predictions using SHAP
- Generates reports and interactive dashboards

**Stack:** `Python` · `FastAPI` · `React` · `Scikit-learn` · `SHAP` · `XGBoost`

### TradeBook — Order Book Engine
[![GitHub](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/raghuviranturkar/tradebook)

Low-latency C++ order matching engine with professional architecture and comprehensive testing.

**Engineering highlights:**
- OOP design with clean separation of concerns
- Order matching with price-time priority
- STL-based data structures for performance
- Unit tested with Catch2
- Build system with CMake

**Stack:** `Modern C++` · `STL` · `CMake` · `Catch2`
